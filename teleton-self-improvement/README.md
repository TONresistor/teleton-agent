# teleton-self-improvement

Teleton plugin for logging learnings, errors, and feature requests.

## Tools

- `log_learning`
- `log_error`
- `log_feature_request`
- `list_learnings`

## Install

Copy this directory to `~/.teleton/plugins/teleton-self-improvement/`.

## Notes

- Uses plugin storage for fast access.
- Also writes to the plugin isolated DB.
