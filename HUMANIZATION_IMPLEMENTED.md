# 🎭 Реализованные улучшения для более человечного поведения

## ✅ Фаза 1: Variable Typing Delays (ГОТОВО)

### Что сделано

1. **Новый модуль `src/telegram/human-behavior.ts`**
   - `calculateTypingDelay()` - расчет времени "печатания" на основе длины ответа
   - `calculateReadDelay()` - задержка перед началом печати (чтение сообщения)
   - `shouldShowTyping()` - интеллектуальное решение показывать ли typing
   - `isSimpleAcknowledgment()` - детекция простых ответов типа "ок", "да"
   - `calculateReactionDelay()` - естественная задержка перед реакцией

2. **Интеграция в message handler** (`src/telegram/handlers.ts`)
   - Задержка перед началом typing (имитация чтения)
   - Variable typing delay зависит от длины ответа
   - Короткие ответы типа "ok" могут пропускать typing (50% шанс)
   - Группы получают ответы на 40% быстрее (меньше думаем в groups)

3. **Интеграция в heartbeat** (`src/heartbeat.ts`)
   - Проактивные сообщения тоже используют human-like delays
   - Fallback на конфиг `reply_delay_ms` если typing отключен

### Параметры по умолчанию

```typescript
baseDelayMs: 800        // Базовое время "думания"
charsPerSecond: 25      // Скорость печати (реалистично)
minDelayMs: 500         // Минимум 0.5с
maxDelayMs: 8000        // Максимум 8с
variancePercent: 30     // ±30% рандомности

// Groups: все задержки × 0.6
```

### Примеры поведения

| Длина ответа | DM задержка | Group задержка | Примечание |
|--------------|-------------|----------------|------------|
| 20 chars (короткий) | ~1.2s | ~0.7s | Может пропустить typing |
| 100 chars | ~2.8s | ~1.7s | Типичный ответ |
| 500 chars (длинный) | ~7.5s | ~4.5s | Серьёзный ответ |
| "ok" (acknowledgment) | 0-1.2s | 0-0.7s | 50% без typing |

## 🧪 Как протестировать

1. Включите `typing_simulation: true` в config
2. Отправьте короткое сообщение ("привет") → быстрый ответ
3. Отправьте длинный вопрос → более долгое "думание"
4. В группе ответы должны быть быстрее чем в DM
5. Простые "ок" иногда приходят без typing indicator

## 📊 Метрики

До улучшений:
- Фиксированная задержка `reply_delay_ms`
- Все сообщения одинаковые
- Не учитывается контекст (DM/group)
